# 📄 Мануал редактора кода VK-постер

## Что это

Встроенный редактор HTML/CSS/JS-шаблона для постов ВК. Открывается из главного окна VK-постер — иконка `✍`.

## Как открыть

На **главном окне** VK-постер нажми иконку `✍` в шапке → откроется попап редактора.

## Интерфейс

### Поля ввода

- **HTML/CSS/JS** — полный шаблон: HTML + стили + скрипт
- **Готовый HTML** — итоговый результат, который отправляется в ВК

### Кнопки

| Кнопка | Что делает |
|--------|------------|
| **📋** | Копировать всё содержимое в буфер обмена |
| **🗑** | Очистить поле (см. галочку «подтверждать» ниже) |
| **☑ подтверждать** | Включить/выключить подтверждение перед очисткой |
| **?** | Открыть эту справку |

## Галочка «☑ подтверждать»

Определяет, что произойдёт после клика на 🗑:

### ☑ Галочка стоит → С ПОДТВЕРЖДЕНИЕМ

1. Клик 🗑 → **текст НЕ удаляется**
2. Под полем появляется плашка:
3. Клик **✓ Подтвердить** → текст удалён
4. Клик **✗ Отмена** → плашка закрывается, ничего не происходит

### ☐ Галочка НЕ стоит → СРАЗУ

1. Клик 🗑 → текст **удаляется мгновенно**
2. Показан тост «✓ Удалено»
3. Никаких вопросов

**По умолчанию** галочка не стоит — удаление происходит сразу.

Выбор галочки **сохраняется** в браузере. То есть — выставил один раз, работает всегда.

## Автосохранение

Всё, что вводишь в поля — **сохраняется автоматически** в `localStorage`:
- HTML/CSS/JS — ключ `vp_editor_html`
- Готовый HTML — не сохраняется (генерируется)

**Текст не потеряется** при закрытии попапа, обновлении страницы или перезагрузке браузера.

## Совет по безопасности

Перед большими правками:

1. Нажми **📋** — скопируй весь текущий код в буфер
2. Если сломал — открой блокнот, `Ctrl+V` вставь — восстановишь
3. Или в консоли:
Так у тебя всегда есть резервная копия.

## Где хранится код
Если браузер очистит `localStorage` (очистка кэша, другой браузер) — код пропадёт. Поэтому важные правки копируй (📋) в блокнот.

## Горячие клавиши

| Комбинация | Что делает |
|------------|------------|
| `Ctrl+Shift+R` | Жёсткий релог страницы (обновить после правки) |
| `Ctrl+A` в поле | Выделить весь код |
| `Ctrl+C` / `Ctrl+V` | Копировать/вставить (работает стандартно) |
| `Esc` в модалке справки | Закрыть справку |

## Что видно в консоли браузера

После открытия попапа — ряд диагностических строк:
Если что-то не работает — эти строки покажут, где сбой.

## Частые проблемы

| Проблема | Что делать |
|----------|------------|
| Код не сохраняется | Проверь что поле не пустое, в консоли: `localStorage.getItem('vp_editor_html')` |
| Текст пропал | Копия может быть в буфере обмена (📋). Или открой вкладку «История» в браузере |
| Попап слишком большой | Потяни за угол — размер запомнится автоматически |
| Справка не открывается | Клик `?` рядом с 🗑 → должна появиться модалка |
| Галочка не запоминается | Проверь: `localStorage.getItem('vp_confirm_clear')` → должно быть `'0'` или `'1'` |
