# 📝 Мануал редактора ВК-контента

> Для тех, кто **создаёт посты** (праздники, обряды, календарные тексты).
> Не требует программирования. Не трогает код, Actions, state.
>
> Полный технический мануал (для админа): [MANUAL.md](MANUAL.md)
> HTML-редактор (оформление постов): [MANUAL_CODE_EDITOR.md](MANUAL_CODE_EDITOR.md)

## Что ты делаешь

Создаёшь JSON-файл в `content/holidays/<slug>.json`. Система сама:
- Проверит при публикации
- Отправит пост в ВК в нужный день и время
- Поставит фото, если указано
- Не задублирует (защита через `state`)

Ты **не**:
- Пишешь код
- Запускаешь скрипты
- Правишь Actions или `state-*.json`
- Трогаешь `poster.py`, `post.yml`

## Куда заходить

Два способа, оба пишут в `content/holidays/<slug>.json`:

### Вариант 1 (рекомендуется) — превью-сайт

1. Открой https://bukvica49.github.io/vk-poster/
2. В шапке — `➕ Новый`
3. Заполни форму → Save

### Вариант 2 — Pages CMS

1. https://app.pagescms.org/ → войди через GitHub → `bukvica49/vk-poster`
2. Раздел **Праздники** (holidays)
3. Создать / открыть

Оба варианта: **Save → auto-commit в GitHub**.

## Поля формы

| Поле | Обяз. | Что вписать |
|------|-------|-------------|
| `slug` | да | латиница без пробелов, напр. `den-bogini-makoshi`. Это имя файла и URL |
| `date` | да | **MM-DD**, напр. `11-10` = 10 ноября. Пост выйдет в этот день |
| `text` | да | короткий заголовок карточки, напр. `День Богини Макоши` |
| `image` | нет | путь в `images/`, напр. `/images/makosh.jpg`. **Baseline JPEG** (см. ниже) |
| `info` | нет | ручной инфо-блок (список строк). Пусто = авто |
| `text_md` | нет | текст для VK. `**жирный**`, `*курсив*`, `~~зачёркнутый~~`, ссылки, `#хэштеги`, эмодзи |
| `post_time` | нет | **ЧЧ:ММ** в KRAT. Пусто = 18:00 |

## Как пост выходит

1. Сохранил → файл в `content/holidays/`
2. **GitHub Actions** проверяет **каждый час** (`0 * * * *` UTC)
3. Когда `slavic_now()` (KRAT-дата) **= `date`** файла:
   - Если `post_time` **наступил** → **пост уходит в ВК**
   - Если ещё рано — ждёт следующего тика
4. Защита от дублей: `state-200796423.json` помнит, что отправлено
5. Фото: если указан `image` и файл есть в `images/` — прикрепится

**Пропуск тика:** если GitHub сдвинул/пропустил час — следующий догонит. Пост выйдет всё равно в тот же календарный день.

## Как «заморозить» пост (отменить)

Пока не вышел:
- Поменяй `date` на далёкую дату (`12-31`). Вернёшь настоящую — снова активен
- Или `post_time` на `23:59` и потом не забудь вернуть

Если уже вышел — **скажи админу**, он удалит через API. Сам не пытайся.

## Если пост НЕ вышел

1. https://github.com/bukvica49/vk-poster/actions/workflows/post.yml
2. Посмотри последние run-ы
3. **Красный + `PHOTO_MISSING=1`** → пост ушёл **без фото**. Передай админу
4. **Success** → смотри в ВК
5. **Run не запускался** → GitHub cron мог пропустить. Через 1-2 часа догонит
6. Непонятное — **передай админу**, не пытайся починить
