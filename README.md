## ✨ Очистка эмодзи в редакторе (vp-strip)

**Где работает:** только в попапе `editor.html` (открывается кнопкой `✍` на главной — в новой вкладке).

**Как пользоваться:**
1. Открой `✍` → редактор
2. Вставь текст с эмодзи: `🔥 Внимание🔥 Обряд🌙 хлеб`
3. Кнопка `🚫` в верхней панели → все эмодзи исчезли
4. Кнопка `↩` → текст восстановлен (отмена за одну операцию)

**Диагностика:** в Console (F12) зелёная строка `► vp-strip handler READY (popup) ◄` — значит фича загружена. Если её нет — проверь `_site/editor.html` после `make_preview.py`.

**Известное ограничение:** в SPA-модалке на главной (если когда-то активируется) кнопки 🚫 нет — это отдельная задача, вне текущего скоупа.
