# vk-poster

Автопостинг славянского календаря (Коляды Даръ) в группу VK + витрина на GitHub Pages.

## Карта репозитория

- `calendar_engine.py` — **единственный** движок календаря: `krugолет(D)` → (год, месяц, день, день недели), `to_gregorian` (обратный поиск), самопроверка `check()` с якорями (`python3 calendar_engine.py` → «ИТОГ: ВСЁ СХОДИТСЯ»)
- `tools/check_canon.py` — охраняемые инварианты канона; запуск: `python3 tools/check_canon.py [гражданский_год]`
- `slavic_calendar.py` — надстройка над движком: `holiday_date`, шапки, info-блоки
- `poster.py` — подбор карточки на слот и публикация в VK
- `state_guard.py` — самолечение state перед каждым тиком
- `make_preview.py` — сборка `_site/` для Pages
- `poster-gui.py` — ручной GUI-инструмент (tkinter), запускается только вручную
- `content/holidays/*.json` — карточки праздников и дней недели
- `config/editor/*.json` — конфиги редактора; `web/` — его исходники
- `images/` — картинки постов; `images/den-dnya/` — девять изображений дней недели
- `state-*.json` — состояние постера (пушится ботом; `.bak` в `.gitignore`)
- `config.main.json` — создаётся CI из секрета `VK_CONFIG`, в репо не хранится

## Канон Круголёта Числобога

- **Структура Лѣт:** 9 месяцев, чередование 41/40 → обычное Лѣто = 365; Священное (16-е Круга, `Y % 16 == 0`) — все по 41 → 369.
- **Круг Кругов:** (15×365 + 369)/16 = 365,25 дня — юлианский темп; внутри Круга гражданские даты гуляют до 3 дней и возвращаются на границе Круга.
- **Якорь (один, в `calendar_engine.py`):** 1-й Рамхатъ 7535 = окно 18:00 19→20.09.2026, ANCHOR_WIDX = 7 (Осьмица). Проверен тремя способами: печатная таблица, формула Лѣт (год + 5509/5508 − 7520), внутренняя связность (41 + 28 = 69 дней до 29-го Айлѣтъ).
- **Недельный инвариант:** 41 + 40 = 81 = 9 недель → в обычном Лѣте нечётные месяцы начинаются с одного дня недели, чётные — с другого (сдвиг 5); в Священном каждый месяц на 5 дней позже предыдущего. Охраняет `check_canon.py`.
- **Конвенция окон:** сутки славянского дня = 18:00 D → 18:00 D+1 (KRAT); канонические таблицы показывают день, когда окно **заканчивается** (D+1 от начала). Открытый вопрос: канон Суток Сварога завершает день Поуданью в 19:30 зимнего времени — действующая конвенция 18:00, менять только на границе Лѣта.
- **Все даты — только через движок** (`krugолет` / `to_gregorian` / `holiday_date`). Ручные гражданские даты вне движка запрещены.
- Равноденствие — справочная информация, не якорь (ежегодная привязка несовместима со Священным Лѣтом 369 дней).

## Конвенция постинга

- Порядок при совпадении дат: праздник → 18:00, чертог → 18:30, день недели → 19:00. **Исключение: Чертог Змея — 04:30** (не менять).
- State пушится всегда, даже при `PHOTO_MISSING` (иначе задвоение поста).

## CI — пять процессов

| Процесс | Что делает |
|---|---|
| `post.yml` | Тик каждый час (11:00 UTC = 18:00 KRAT), слоты по `post_time`. Режим `FORCE` — вручную через dispatch. Провал → Issue, успех → авто-закрытие |
| `keeper.yml` | Каждые 30 мин: если последний успешный тик старше 70 мин — будит `post.yml` |
| `pages.yml` | На каждый push в main + дважды в день: `make_preview.py` → `_site/` → Pages |
| `bump.yml` | Issue «bump: slug» или dispatch: снимает `photo_failed`, пост уйдёт сам в следующем году |
| `check-token.yml` | Вручную: проверка VK-токенов из секрета `VK_CONFIG` |

## State

- `state-200796423.json`, бэкап `state-200796423.bak.json` (`.bak` живёт только на раннере).
- `state_guard.py` перед каждым тиком: нет/сломан → восстановить из `.bak`; валиден → обновить `.bak`.

## Как добавить праздник

1. Создать `content/holidays/<slug>.json` с полями: `slavic` (объект `{"month": "Рамхатъ", "day": 4}`), `text`, `slug`, `post_time` ("18:00"). Пример готовой карточки — `content/holidays/den-ivana-omiyaskogo.json`.
2. `slavic` обязателен (канон); `date` (MM-DD) — только fallback, не источник истины.
3. Проверка: `holiday_date(h, год)` должна вернуть дату **начала** окна.
4. Коммит + push: Pages пересоберёт витрину, `post.yml` подхватит сам.

## Известные ограничения

- Попап-редактор: позиция — отложено (Wayland: `screenX/screenY = 0`, `moveTo()` запрещён; варианты: Xorg-релогин или редактор вкладкой).
- Белый попап после чистки кэша: редко, при первом открытии после Ctrl+Shift+R — помогает перезагрузка страницы.
- `PHOTO_MISSING=1` в логе тика: пост вышел без фото — чинить `user_token`.

## Редактор: очистка эмодзи (vp-strip)

**Где работает:** только в попапе `editor.html` (открывается кнопкой `✍` на главной — в новой вкладке).

**Как пользоваться:**
1. Открой `✍` → редактор
2. Вставь текст с эмодзи
3. Кнопка `🚫` в верхней панели → все эмодзи исчезли
4. Кнопка `↩` → текст восстановлен (отмена за одну операцию)

**Диагностика:** в Console (F12) зелёная строка `► vp-strip handler READY (popup) ◄` — значит фича загружена. Если её нет — проверь `_site/editor.html` после `make_preview.py`.

**Известное ограничение:** в SPA-модалке на главной (если когда-то активируется) кнопки 🚫 нет — отдельная задача, вне текущего скоупа.
