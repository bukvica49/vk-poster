# 🖥️ Клиентская панель превью-сайта

> Функции страницы https://bukvica49.github.io/vk-poster/, которые работают **в браузере посетителя**.
> **НЕ связаны с автопостингом.** Автопостер — в [MANUAL.md](MANUAL.md).
>
> Файлы: `web/app.js` (исходник) → `_site/app.js` (сборка). Копирует и подключает `make_preview.py`.

## Что это

Один файл `web/app.js` (~204 строки, IIFE, без зависимостей) подключается к `_site/index.html` через `<script src="app.js" defer>`. Даёт: **поиск** по карточкам, **панель настроек вида** (ночной режим, фон), кнопку **↑ Наверх**.

Две точки касания с `make_preview.py` (около строк 63 и 264): копирование `web/app.js` → `_site/app.js` и вставка `<script>` в шаблон. Если `web/app.js` нет — копирование молчит, сборка не падает.

## Поиск

- Поле сверху. Фильтрует карточки по названию, дате, slug и всему тексту.
- Примеры: `щука`, `нояб`, `05.11`, `2026`, `rodomira`.
- **Escape** в поле — сброс.
- `cardIndex` собирает строку-индекс из `h2`, `.meta`, `data-slug`, `span.when` (с развёрнутой формой) и `textContent` → сохраняет в `card.dataset.vpIdx` (не пересчитывается на каждый ввод).
- `expandDate("05.11.2026 18:00")` → варианты: `05.11`, `05.11.2026`, `11.05`, `2026-11-05`, `2026`, `ноябрь`, `ноя`, `5 ноя`.
- `doFilter` — простой `includes` со счётчиком.

## Настройки вида

- Кнопка рядом с поиском.
- Панель `vp-settings-panel` скрыта, показывается по клику.
- Вставляется через `h1.insertAdjacentElement('afterend', bar)` — **цепляется за `<h1>VK Poster</h1>`**.
  ⚠️ Если `h1` убрать или переименовать — панель не вставится (ничего не сломает, но пропадёт).
- Ночной режим (`theme: "dark"` или отсутствует).
- Фон страницы.
- Хранение — `localStorage['vp-prefs']`.

## Формат `vp-prefs`

| Ключ | Что |
|---|---|
| `theme` | `"dark"` или отсутствует |
| `background` | URL из `images/` или data-URI |
| `userBackgrounds` | `map {dataURI: {name, added}}` |

Инициализация: `prefs` читается при загрузке, отсутствующие поля = дефолты. `applyTheme` и `applyBackground` выполняются **до** `buildUI` — чтобы не было мигания светлой темы. `buildUI` вызывается по `DOMContentLoaded`.

## Фон

`applyBackground` создаёт `div#vp-bg-overlay.vp-bg-overlay` в `body` (position:fixed, z-index:-1), opacity `.22` в светлой теме, `.14` в тёмной.

`collectBackgrounds` собирает `img src` из всех карточек + ключи `prefs.userBackgrounds`. Загрузка через `FileReader.readAsDataURL` → `prefs.userBackgrounds[dataURI]`.

**Лимит 4 МБ** в `change` — не грузим больше. Реально влезает **3–4 фоновых JPEG** (base64 +33% размера, localStorage ~5–10 МБ на origin).

Фон в инкогнито **не сохранится** — localStorage изолирован.

## Кнопка ↑ Наверх

На главной (`_site/index.html`) в правом-нижнем углу появляется **квадратная** кнопка `↑` (`border-radius: 10px`) при прокрутке > 300px.

Цвет подстраивается под тему: light → `#2563eb` / белый `↑`, dark → `#374151` / `#f9fafb`. Тема определяется через `data-theme` → luminance фона `body` → `prefers-color-scheme`, перекрашивается через `MutationObserver` при переключении темы.

Клик → `window.scrollTo({top:0, behavior:'smooth'})`. Стили инлайн, `z-index: 9999`. В редакторе (`✍`) **не появляется** — там свой скролл на 7/10 строк.

Источник: `web/app.js`, IIFE `_vpInitBackToTop` в конце файла.

## Как править
⚠️ После пуша — **Ctrl+Shift+R** (hard refresh). GitHub Pages отдаёт HTML с `Cache-Control: max-age=600`.

## Что НЕ реализовано (контекст, не «сломано»)

- Загрузка фона в репозиторий для всех посетителей (нужен GitHub PAT в браузере).
- Общие настройки для всех (писать в HTML при сборке через `web/prefs.json`).
- Отдельная папка `backgrounds/`.
- Ссылка вида `?bg=images/x.jpg&theme=dark`.
- Кнопка «сегодня» / «на этой неделе».
- Сортировка или группировка по месяцам.
- Экспорт/импорт настроек.

## Ограничения

- `h1 "VK Poster"` **обязателен** — панель цепляется за него.
- localStorage ~5 МБ (хватает на 3–4 фона).
- 4 МБ на фон — жёсткий лимит в `change`.
- Фон в инкогнито **не сохранится**.
- Настройки **привязаны к браузеру** — между устройствами не синхронизируются.
