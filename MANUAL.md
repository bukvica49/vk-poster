# 🆕 Изменения 20.11.2026

## Кнопка ⏭ на карточке — пометка «вышел без картинки»

### Как работает
1. Пост вышел в ВК **без картинки** (PHOTO_MISSING: токен/Flood/upload-глюк)
   → `poster.py` сам ставит посту флаг `"photo_failed": true` в JSON.
2. На карточке поста появляется кнопка **⏭** (рядом с ✏️ и 📋).
3. Пост **уходит в конец списка с пересчётом даты**: posted-логика make_preview
   пересчитывает дату карточки на следующий occurrence (перпетуально, по
   slavic-якорю). Карточка держится внизу постоянно — её дата самая дальняя.
   Очередь всегда честная, по датам, не сбивается.
4. Нажал ⏭ → GitHub открывает форму issue с готовым заголовком
   `bump:<slug>` → жмёшь **Create** → workflow `bump.yml` снимает флаг
   `photo_failed` (кнопка исчезает с карточки) и закрывает issue.
5. При следующей публикации **с картинкой** постер сам чистит все флаги.

### Важно
- ⏭ появляется ТОЛЬКО у постов, вышедших без картинки.
- В день поста кнопка видна (если картинка не ушла).
- Карточка НИКОГДА не скрывается с сайта — все посты всегда в списке.
- Безопасность: bump.yml срабатывает только на issue от `bukvica49`.

### Диагностика
- Флаг снят? `grep photo_failed content/holidays/<slug>.json` → пусто = ОК.
- Кнопка осталась на live? Сайт пересобирается 2×/сутки; сразу:
  `gh workflow run pages.yml --repo bukvica49/vk-poster`

### Файлы фичи
- `poster.py` — `_set_photo_flag(text, failed)` + вызовы после `post()`.
- `make_preview.py` — `'photo_failed'` в rows, `{defer_btn}` в карточке.
- `.github/workflows/bump.yml` — issues:opened → снятие флага.
- `.github/workflows/post.yml` — `git add` включает `content/holidays/*.json`.

### Кнопки карточки (полный список)
- `✏️` — редактировать (PagesCMS deep-link)
- `📋` — скопировать текст для VK
- `⏭` — «пометку обработал» (только у постов, вышедших без картинки)
